# LPForge Phase 4 Implementation Package v1.0

## Mandate
Phase 4 converts Phase 3 recommendations into paper-only entry timing, capital/risk decisions, simulated position lifecycle and forward-EV management. It is not an execution phase.

## Non-negotiable boundary
No transaction building, signing, sending, live wallet secret, live add/remove liquidity, swap, claim, rebalance or live exit path is permitted.

## Core chain
Phase 3 thesis → Entry Timing → Entry Delay → Capital Allocation → Risk Governor → Paper Position → Thesis Monitor → Forward EV → HOLD / RESHAPE / REBALANCE / REDUCE / CLOSE → Portfolio Forensics.

## Exit criterion
Phase 4 exits only when P4-01..P4-16 are green, full P1–P4 regressions are green, M0001–M0010 are valid, the paper runtime is recommendation-only/paper-only, and management outcomes can be measured against no-management counterfactuals.
